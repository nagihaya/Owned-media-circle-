# T-Biz メディア — Googleフォーム受付版

2026-10-30の依頼に合わせ、お問い合わせ・取材依頼・協賛相談・メンバー募集をGoogleフォーム方式へ変更しました。既存の青・白・黒のデザイン、ナビ、中央スライド、タグ検索、インタビュー/ビジネス知識ページは維持しています。正式サイト名は「未定」、サブタイトルは空欄で、編集画面から変更できます。

## Googleフォームを挿入する

編集ログイン後、上部の「Googleフォーム」を開きます。「お問い合わせ共通」「取材依頼」「協賛相談」「メンバー募集」の4枠に、それぞれGoogleフォームの回答者URL、またはGoogleのiframe埋め込みコードを貼り付けてください。表示高さは350〜3,000px、初期値1,000pxです。「プレビュー」で確認し、「Googleフォーム設定を保存」で共有DBへ保存します。公開ページを再読み込みすると全員に反映されます。

お問い合わせ共通・取材依頼・協賛相談は `/contact` の切替リンクで表示し、メンバー募集は `/recruit` に表示します。共通フォームだけ登録して、Googleフォーム内で相談区分を選んでもらう運用も可能です。空欄は非表示、すべて未設定なら準備中表示です。現在、実際のフォームURLは未提供のため未設定です。

ページ内埋め込みには `https://docs.google.com/forms/.../viewform` の回答者用URLを使います。`forms.gle` の短縮URLも保存できますが、外部リンクとして表示します。Googleフォームの編集用URL（末尾edit）は使えません。貼り付けたiframeコードからはURLだけを取り出し、任意HTMLやスクリプトは実行しません。iframeには読み上げ用タイトルを付け、スマートフォンでは幅100%で表示します。表示できない場合に備え「別のタブで開く」も併設しています。

## Google側で行う設定

Googleフォームを公開し、回答対象を確認してください。一般公開する場合は回答者アクセス権を「リンクを知っているすべてのユーザー」にします。回答者リンクは公開済み画面やプレビューからコピーできます。HTML埋め込みコードはGoogleフォーム右上のその他メニューから「HTMLを埋め込む」で取得できます。[1]

問い合わせの区分、会社/団体名、担当者名、メールアドレス、担当者の電話番号、内容、プライバシーポリシーへの同意は、Googleフォーム側ですべて必須に設定してください。本サイトの編集画面はGoogleフォームの質問や必須設定を変更しません。回答者が想定どおり開けるか、Googleにログインしていないブラウザでも公開範囲を確認してください。

管理者への通知は、Googleフォームの「回答」→その他メニュー→「新しい回答についてのメール通知を受け取る」で設定します。[2] 回答者向けには、Googleフォームでメールアドレスを収集し、必要に応じて「回答のコピー」を送る設定を行ってください。回答コピーは独自文面の自動返信とは別です。カスタマイズした自動返信はこのサイトからは送信せず、別のGoogle側運用が必要です。[2]

受付から半年以内の削除は運営側で行ってください。Googleフォームの回答だけでなく、連携するGoogleスプレッドシート、ダウンロードしたCSV、通知メールなどに残る個人情報も対象です。本サイトはGoogle側の回答を取得したり、自動削除したりしません。プライバシーポリシーはGoogleフォーム利用・Google上の回答管理に合わせて更新しました。制定日と運用実態を運営で最終確認してください。

## サイト側で不要になったもの

問い合わせ用SMTP、Gmailアプリパスワード、通知先の秘密設定は今回の受付では不要です。サイト内の旧送信API `/api/contact` は410で停止し、新規回答を受付DBへ保存しません。サイトからの通知・自動返信・メール再送も停止しました。フォーム設定とGoogleフォームのURL以外に、回答内容を本サイトへ転送しません。

過去の問い合わせデータは勝手に削除せず、従来の保存期限に従う処理を保持しています。期限処理はGoogle側の回答には触れず、旧サイト受付・セッション等のデータだけを対象にします。旧SMTPコードは移行履歴として残っていますが、本番の公開/編集/定期実行からは呼び出しません。

## 維持したメディア機能

サイト・スライド・記事・タグ・ロール・ページ閲覧とnote送客件数は共有MySQLへ保存します。localStorageは使いません。記事タイプは経営者インタビュー/若手社員インタビュー/座談会/ビジネス知識の4種、不明はNULLで未分類表示。並べ替えは投稿日です。トップh1は視覚的にのみ隠しています。提供されたT-Bizロゴを同梱しています。

RSSは最大25件を先に蓄積し、note URLで重複防止、配信から外れた過去記事と手動編集を保持します。記事のAI/画像処理はDBキューで行い、AIの選択肢は固定、月100呼び出しのアプリ側上限を維持しています。画像は容量・画素・SSRFを検証してWebP圧縮/メタデータ除去後、永続ストレージへ保存します。実noteマガジン/RSS/過去記事URL・実写真・募集内容は未提供です。

## 開発・公開

Node.js 24で `npm ci` → `npm run migrate` → `npm start`。ローカルは宣言済み3000ポートの127.0.0.1、公開Dockerは環境のPORTで0.0.0.0に待ち受けます。`/health`はDBの正常性を確認します。ファイルを直接開く方式ではなく、Manusのプレビューから表示してください。共有DBを使うため、検証のための記事・ユーザー・問い合わせを本番テーブルに投入しません。

初期管理者の `TBIZ_ADMIN_EMAIL` と公開/プレビュー許可オリジン `TBIZ_PUBLIC_ORIGIN` / `TBIZ_PREVIEW_ORIGIN` は引き続きサーバー側設定です。ManusがDB、認証、AI/画像サービスの資格情報を提供します。これらをブラウザへ渡しません。

公開後のRSS（1日3回）と旧データ/セッション期限処理（毎日）は、HTTP定期ジョブで登録しタスクUIDを管理画面で関連付ける構成です。POST先は `/api/scheduled/run`。ジョブ登録・実行はまだ未完了です。Google回答の自動削除ジョブは設けていません。

`npm run check`で構文・EJS・未定義変数・公開秘密混入、`npm test`で日付・URL・権限拒否・GoogleフォームのURL/表示/設定検証を行います。UIの実アカウント保存や実フォーム回答の送信とは区別します。無料仮URLは実際の公開成功後に案内します。ホスティング・AIの料金は利用枠に依存し、月額0円を保証しません。
